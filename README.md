# Time On Site Analysis - E-Commerce Sector  

This repository contains the Time On Site Analysis project for an e-commerce company. The analysis focuses on understanding user engagement by measuring session duration, bounce rates, and activity patterns across devices, referral sources, and pages. The project provides actionable insights to improve customer experience and site performance.

---

## Key Highlights

### Objective:
Analyze user behavior patterns on the website based on time spent, identify high and low engagement pages, and derive strategies to enhance user retention and conversions.

### Techniques Used:
Data Cleaning, Time-on-Site Calculation, A/B Testing, Heatmap Visualization, Engagement Metrics Analysis, Bounce Rate Evaluation.

---

## Features

### Data Preparation:
- Cleaned and pre-processed raw user session data.
- Handled missing values and removed duplicates.
- Generated accurate Time-on-Site metrics using session timestamps.

### Time Spent Analysis:
- Analyzed average time spent by:
  - Device Type (Desktop, Mobile, Tablet)
  - Referral Source (Direct, Email, Search Engine, Social Media)
  - Geographic Location
- Identified high & low engagement pages based on total time spent.

### Bounce Rate Assessment:
- Evaluated bounce rates for Desktop, Mobile, and Tablet users (30% each).

### A/B Testing:
- Compared High Engagement Pages vs Low Engagement Pages:
  - Average Time Spent (High Engagement): 150.71 sec
  - Average Time Spent (Low Engagement): 17.90 sec
  - Conversion Rate (High Engagement): 9.76%
  - Conversion Rate (Low Engagement): 10.71%

### Heatmap Creation:
- Visualized peak user activity across:
  - Day of Week
  - Hour of Day
- Peak activity observed during late-night and early-morning hours, especially on weekends.
